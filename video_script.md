## 🇬🇧 ENGLISH VERSION

### Introduction (30 seconds)

Welcome to the CALIBER demo - Carbon-Aware LLM-Integrated Benchmarking and Eco-friendly Rewriting.

CALIBER is a comprehensive tool for SQL query generation via artificial intelligence, with a unique feature: real-time CO₂ emissions monitoring and green query optimization.

The tool is organized into 6 main tabs:

Data Hub: allows you to load data from local files like CSV, Parquet, or HDF5, or connect to existing databases such as MySQL, PostgreSQL, SQLite, and DuckDB. Here you also configure LLM models for query generation.

Data Insights: provides in-depth dataset analysis with detailed statistics, automatic sensitive data detection, relational profiling, and interactive visualizations.

Green Query Builder: the heart of the system. Generates SQL queries from natural language using LLMs, with real-time CO₂ monitoring. Includes the Greenify function that automatically optimizes queries by reducing carbon emissions.

Eco Benchmark: compares different LLM models based on energy efficiency, accuracy, and carbon footprint. Includes comprehensive benchmarks to evaluate both models and databases.

Synthetic Lab: generates synthetic datasets with various strategies like Faker, GaussianCopula, CTGAN, and TVAE, while monitoring the environmental impact of each approach.

Settings: allows you to customize key parameters such as CO₂ emission factor and CPU TDP for accurate estimates based on your hardware.

CALIBER's distinctive features are:

- Real-time CO₂ Monitoring: complete tracking of energy consumption during all operations
- Green Optimization with Greenify: automatic query rewriting to reduce environmental impact
- Multi-LLM Support: integration with Hugging Face, Ollama, LM Studio, and custom models
- Comprehensive Benchmarking: systematic comparison based on sustainability metrics
- Synthetic Data Generation: with energy impact tracking
- Advanced Analytics: relational profiling and sensitive information detection

Getting started is simple: load your data, configure an LLM model, and start generating sustainable queries. CALIBER will show you exactly how much each operation costs in terms of CO₂.

Let's start the demo!
